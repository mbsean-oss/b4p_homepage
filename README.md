# Notion-driven Homepage + Blog

A production-ready template that turns a Notion workspace into a fast, branded business website and blog, statically generated with [Astro](https://astro.build/) and deployed on [Cloudflare Pages](https://pages.cloudflare.com/).

## Why this stack

- **Notion as CMS** — non-developers edit content in a familiar interface.
- **Astro** — ships pure HTML/CSS (very fast, SEO-friendly).
- **Cloudflare Pages** — free tier covers custom domains + global CDN.

## Quick start

```bash
# 1. Install
npm install

# 2. (Optional) configure Notion
cp .env.example .env
# fill in NOTION_TOKEN and database IDs

# 3. Run locally
npm run dev

# 4. Build static site
npm run build

# 5. Preview production build
npm run preview
```

The site renders with **mock content** by default — you don't need to set up Notion to see the result. As soon as you fill in the `.env` and connect your Notion databases, real content takes over.

## Notion DB schemas

### `Site Pages DB`

| Property | Type | Purpose |
|---|---|---|
| title | Title | Page title |
| slug | Text | URL slug |
| page_type | Select | home/about/services/contact/privacy/legal |
| published | Checkbox | Visibility |
| nav_visible | Checkbox | Show in header? |
| nav_order | Number | Header sort order |
| excerpt | Text | Short summary |
| seo_title | Text | `<title>` |
| seo_description | Text | `<meta description>` |
| cover_image | Files | Optional cover |
| og_image | Files | Open Graph image |

### `Posts DB`

| Property | Type | Purpose |
|---|---|---|
| title | Title | Post title |
| slug | Text | URL slug |
| published | Checkbox | Visibility |
| published_at | Date | Publish date |
| category | Select | Blog category |
| tags | Multi-select | Post tags |
| excerpt | Text | Summary, shown on list/detail |
| cover_image | Files | Cover image |
| seo_title | Text | `<title>` |
| seo_description | Text | `<meta description>` |
| canonical_url | URL | Canonical override |
| featured | Checkbox | Marks a post for the home "featured" section |
| source_type | Select | original / migrated_from_naver / summary_from_naver |
| legacy_url | URL | Original Naver (or other) URL when migrated |
| noindex | Checkbox | Sets `<meta name="robots" content="noindex">` |

## Deploy to Cloudflare Pages

1. Push the repo to GitHub.
2. In Cloudflare Dashboard → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Select the repo.
4. Set the build command: `npm run build`
5. Set the build output directory: `dist`
6. Set environment variables (in **Settings → Environment variables**):
   - `NOTION_TOKEN`
   - `NOTION_PAGES_DB_ID`
   - `NOTION_POSTS_DB_ID`
   - `SITE_URL` — your canonical URL, e.g. `https://example.com`
   - `SITE_NAME`, `SITE_DESCRIPTION`
7. Save and deploy.

Every `git push` will trigger a redeploy automatically. Cloudflare Pages also creates a unique preview URL for every commit, with `X-Robots-Tag: noindex` applied automatically — convenient for review without polluting search results.

## Connect a custom domain

1. In Cloudflare Dashboard → **Workers & Pages** → your project → **Custom domains** → set up your apex or subdomain.
2. If you used an external registrar, point nameservers to Cloudflare (or, if you keep external DNS, add a CNAME / A record pointing to the Pages project).
3. Cloudflare provisions a free SSL certificate automatically — you don't need to do anything else.

## Custom design

- Brand colors and fonts: edit `src/styles/global.css` (`--color-accent`, `--font-body`, etc.).
- Layout and components: edit files under `src/components/` and `src/layouts/`.
- Page-add copy and structure: edit `src/pages/`.

The styles are intentionally focused on **looking nothing like Notion** — generous whitespace, custom typography, branded color tokens, no Notion fonts or chrome.

## Operational loop

1. Write or edit content in Notion.
2. Set `published = true` (and check the slug, SEO meta, cover image, category).
3. Push to the `main` branch of your Git repo (or trigger a manual deploy).
4. Cloudflare rebuilds the static site with the updated content.
5. Site is updated globally within ~1 minute.

## Notes on SEO

- `<title>` and `<meta description>` come from `seo_title` / `seo_description`.
- `sitemap-index.xml` is auto-generated by `@astrojs/sitemap`.
- `robots.txt` is shipped in `public/`.
- Canonical URLs are derived per page from `Astro.url`.
- Preview deploys are excluded from indexing by Cloudflare Pages automatically.
